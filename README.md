# Hermes Dashboard — wtyczka Hermes

Pasek statusu Hermes Desktop: praca botów, koszty modeli i providerów, limity.

Instalacja (tylko część Desktop): `hermes://plugin/install?repo=Paullina26/hermes-dashboard&enable=1`

- `desktop/plugin.js` — element paska statusu
- `dashboard/plugin_api.py` — backend `/api/plugins/hermes-dashboard/`
